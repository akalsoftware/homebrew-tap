# Akal Software Homebrew tap

```bash
brew install akalsoftware/tap/supaforge
```

| Formula | |
| --- | --- |
| `supaforge` | [SupaForge](https://github.com/akalsoftware/supaforge): find and fix drift between Supabase environments — schema, RLS, roles, auth, storage and more. |

On an Intel Mac, Homebrew builds Node.js from source, which takes a long
time; `npm install -g @akal/supaforge` is quicker there.

The formulae follow each tool's releases automatically. Upgrade with
`brew update && brew upgrade`.

DBDiff, SupaForge's diff engine, has a tap of its own:
`brew install dbdiff/dbdiff/dbdiff`.
